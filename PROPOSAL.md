# CPS310 Zombie Game Proposal

**Status:** Working outline for team discussion

## Project background

CPS310 Zombie Game is an agent-based simulation in which civilians, armed civilians, and zombies interact in a shared arena. The current Stage 2 implementation supports 10,000 agents, uses spatial partitioning and multiprocessing for target searches, displays population changes in Tkinter, and logs completed runs to PostgreSQL.
